# 功能建议清单（2026-10-12）

> 前提：**所有功能先做鸿蒙版，固化后再同步到 Windows 版**（按你的要求）。
> 标注：🔥 我建议优先做 · 💡 有意思但不急 · 🧪 需要额外数据源/权限 · ⏳ 远期

## 一、打印机（拓竹）—— 已经落了第一步，往下能接很多

**已完成**：桥端 `--printer http://127.0.0.1:8790/api/state` 拉取 + 鸿蒙版打印机卡片
（状态/进度/层数/剩余/ETA/喷嘴·热床·腔温/风扇/速度/AMS 托盘色块/HMS 告警），
真机验证过打印中与告警两种状态。

| 建议 | 说明 | 代价 |
|---|---|---|
| 🔥 **HMS 告警中文** | bambuhelper 那边已经把官方 HMS 全表（~194KB）编进固件了，桥端复用同一份表，把 `0300_0100_...` 翻成「热端 fan 转速异常」这类原文。屏幕上直接看懂，不用查手机 | 桥端加映射表 + 面板多一行 |
| 🔥 **打印完成/失败时醒目提示** | 完成时整块卡片闪绿 + 显示用时/耗材估算；失败时整屏边框变红呼吸 30 秒（一眼瞟到） | 小 |
| 💡 **耗材与时长统计** | `bambu-monitor` 已经有 `usage.json`（monitoredSec/totalSec）。面板加一行「今日打印 3h20m · 耗材 128g · ≈¥32」 | 小 |
| 💡 **最近打印历史轮播** | 最近 5 次：文件名 / 结果 / 用时，与「用量/时钟」面板轮播 | 中 |
| 💡 **多打印机** | 你已经有第二台的话：卡片每 10 秒轮换一台，或按「正在打印的那台优先」 | 中 |
| 🧪 **腔体摄像头缩略图** | P2S/X1 有内置摄像头（RTSP/JPEG）。VM 面板已经有取图通路，再开一路即可 | 中，依赖机型 |
| ⏳ **首层/炒面 AI 检测** | 有摄像头才能谈，本地跑模型不现实 | 远期 |

## 二、DSH 会话与工作流（这块是你最初的需求，还能再深）

| 建议 | 说明 | 代价 |
|---|---|---|
| 🔥 **"正在做的这一条"高亮** | 待办面板现在只显示完成数；把 `in_progress` 那条单独放大 + 进度条（已完成/总数） | 小 |
| 🔥 **长任务完成提醒** | DSH 从 busy 转 idle（或 turn 结束）时，屏幕来一次轻提示（边框脉冲 + 一行「任务完成 3m12s」） | 小 |
| 💡 **最后 3 条工具调用时间线** | 桥端已经能看到 tool 名，做成 `bash → read → edit` 的短时间线，比只显示当前工具信息量大 | 小 |
| 💡 **今日 Token 按小时柱状图** | 桥端已有全量扫描能力，聚合成 24 个柱，比一个总数有信息量 | 中 |
| 💡 **多会话/多项目切换** | 桥端扫 `~/.dsh/sessions/*`，屏幕上按项目轮播或手动切 | 中 |
| 💡 **花费预算条** | 设个日预算（如 $5），超 80% 变黄、超 100% 变红 | 小 |
| ⏳ **屏幕反向控制 DSH**（继续/停止/新建会话） | 需要 DSH 侧的受控接口，风险高，建议单独设计 | 远期 |

## 三之二、VM 画面本身的几个可选增强

| 建议 | 说明 | 代价 |
|---|---|---|
| 💡 **VM 画面暗罩 / 自动降亮** | 被监控桌面有大面积白窗时（实测占 62%），整块副屏会被"点亮"、夜里刺眼。加一层 30-40% 黑罩或按时间自动降亮即可压下去。**注意这会偏离 ArkTS 原版观感**，所以列为待你拍板项（一行 FillRectangle 的事） | 小 |
| 💡 **VM 画面裁掉任务栏** | 若只想看内容不想要任务栏，可裁掉底部固定高度 | 小 |
| 💡 **VM 画面轮播** | 多台被监控机器时轮播 | 中 |

## 我的建议顺序（如果一次只做一件）

1. **HMS 告警中文 + 打印完成/失败提示** —— 打印机的"事件感"最强，做完这块副屏就真的"会说话"了。
2. **待办高亮 + 长任务完成提醒** —— 你最常用的 DSH 场景，收益立刻可见。
3. **相框模式** —— 让屏幕在没活干的时候也有价值，且实现很小。
4. **网页配置页** —— 之后所有功能都能少改一次代码。

要哪几个？直接说编号或名字，我按鸿蒙版先做，做完你在平板上验，固化后再同步 Windows 版。
