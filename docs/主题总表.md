## 五、字体体系

| 用途 | 字体 | 说明 |
|---|---|---|
| 大数字/时间 | 等宽（`F.monoFont`） | 数字不跳动 |
| 标签/标题 | 无衬线（`F.font`） | |
| 次要信息 | `F.fontSub` / `F.monoSub` | 带 `scaleSub` 缩放 |

**已做的字体优化**（用户反馈"字看着虚"之后的动作）：

1. 文字型主题（5/6）JPEG 质量抬到 0.95（局部变量，不污染其它主题）——
   实测文字边缘梯度中位 **45 → 64**
2. 字号按官方原图对齐（主题 7：标题 80px / 主数值 100px / 次数值 80px）
3. `Dashboard.monoFit()`：等宽大字按 `measureText` **自动降字号**，
   解决 `HH:mm` 超出面板被裁的问题
4. 4:2:0 色度抽样**预补偿**：纯蓝 `#0000FF` 解码后几乎归零（屏上蓝砖 0 像素），
   改用 `#3A55E0` 一组后蓝砖 **1362 像素**；打砖块与固件仿真屏已统一同一套值

## 六、漏光补偿（vig）

| 参数 | 当前值 | 说明 |
|---|---|---|
| `vignette` | 0.25 | 强度 |
| `vignetteReach` | 620 | 影响半径 |
| 角 | 随旋转自适应 | rotate180 时压缓冲区**左上角**才能压到物理右下角（实测四角验证过） |

实测：vig=70 时物理右下角 **−8.3**、左上角 **+0.2**（不误伤）。
主题 4/5/6/7/8/9 自行绘制补偿，兜底分支已排除它们（避免叠加两次）。
