## 一、参照项目是什么

中心一颗银灰光球，五只发光水母代表五个模块（作品库/概念网络/方法库/选题池/创作台）；
点水母 → 光球退到左侧、水母列队、**触须像伞一样展开**到每篇内容；点一篇 → 右侧滑出分析栏；
底部「问你的图谱」用本地规则检索，不调 AI；毛玻璃面板 + 银灰/香槟金配色；尊重"减少动态效果"。

## 二、本工程借了哪几样（都已实装并实测）

| 借的东西 | 在本工程里的落点 |
|---|---|
| **三层下钻 hub → 模块 → 单条** | hub=工具束总览；点束 → 该工具的调用展开；点一条 → 右侧分析栏；Esc / 面包屑逐层返回 |
| **触须伞状展开的缓动** | `umbrellaEase(k)=1-(1-k)^2.4`、`umbrellaDist(base,range,v,k)` —— 照其公式实现，用于展开动画（620ms） |
| **右侧滑出分析栏** | 单次调用详情：耗时 / 返回大小 / 该工具总量 / 前后相关事件 / 原始 JSON |
| **毛玻璃 + 银灰/香槟金** | 新增 `--glass/--glass-strong/--gold/--rose`，面板 `backdrop-filter`；金色只用于高亮与分析栏 |
| **粒子迸发（orb-dust）** | 工具调用时从黑洞边缘喷 8~22 颗粒子（带重力与衰减），独立 canvas |
| **尊重 prefers-reduced-motion** | 命中即关掉字符雨/粒子/生长动画，数据照常刷新 |
| **「问你的图谱」本地问答** | 底部「问图谱」：最慢的调用 / 哪个工具最多 / 今天用了多少 token / JEV 怎么说 / 当前会话 / 副屏状态（纯本地规则，不调 AI） |

## 三、刻意没照搬的

- **它的数据模型**（Obsidian vault 导入 + localStorage）——本工程的数据源是 DSH 实时遥测，不适合搬；
- **银灰光球 + 水母本体**——本工程保留自己的黑洞/光纤/字符雨视觉，只把**交互与材质**融进来；
- 它的中英双语与内页（作品库/创作台/选题池）——与副屏看板无关。

## 四、为验证顺手做的两件基础设施

| 设施 | 用途 |
|---|---|
| `?drill=<工具>` / `?q=<问题>` 深链 | 打开页面即进入指定状态（分享/复现某个视图） |
| `POST /api/ui`（服务端下发 UI 指令）| 一条 curl 让正在看的页面下钻/提问/复位。**实机截图验证时靠坐标点击太脆**（我点偏过两次，一次打到问答按钮、一次弹出右键菜单），有了这条通道就能稳定复现任意状态 |
