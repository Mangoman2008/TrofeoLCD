### 1.3 球发射 / 反弹规则

- 从挡板发射：`hit` 夹到 0.08–0.92，角度 = `150 − hit×120 + jitter`，再夹到 30–150°；`|vx|<1.2` 补到 ±1.2，`|vy|<1.0` 补到 −1.5 → `clock_pong.cpp:289-308`
- 边界反弹：左右 `|x|` 到位夹住并取反 vx，顶部 `|y|` 同理；底部越界 `spawnBall()` 重发（中点 + ±5° 随机）→ `clock_pong.cpp:494-499、524、330-335`
- 砖块碰撞：命中即灭砖，按重叠量小的一侧决定反弹轴（累计判定，非逐块），并把球推出砖区 → `clock_pong.cpp:442-474`
- 挡板追踪：球下落时追球心，球上升时回画布中心，差 >2 才走，速度上限 14 → `clock_pong.cpp:420-439`

### 1.4 绘制顺序与样式

顺序（`clock_pong.cpp:784-826`）：**球 → 挡板 → 日期 → 时间**；首次进入先 `fillScreen(黑)` → 铺砖 → 发球 → 画日期/时间（`716-736`）。

| 元素 | 画法 |
|---|---|
| 砖块 | `fillRect(色)` + 顶边 1px 白 + 底边 1px 黑 → `261-268` |
| 球 | 白色实心圆，直径 20（源注释：240 基准 4px 的 5 倍 "变大500%"）→ `380-408` |
